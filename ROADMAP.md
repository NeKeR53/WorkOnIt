# Roadmap

La roadmap indique une direction, pas un engagement de calendrier. Les décisions
et propositions détaillées vivent dans les issues GitHub.

## Prochaine version

- stabiliser les formats d'import/export et documenter leur compatibilité ;
- améliorer le confinement et la confirmation des commandes locales ;
- signer et notariser les artefacts macOS et Windows ;
- compléter tests d'accessibilité et scénarios desktop ;
- documenter migrations et procédure de récupération.

## Plus tard

- mises à jour intégrées avec signature cryptographique ;
- extensions déclaratives avec permissions minimales ;
- paquets Linux supplémentaires selon demande communautaire.

Les contributions sont bienvenues. Commencez par une issue décrivant le besoin,
les risques et le comportement attendu.
