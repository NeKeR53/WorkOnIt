# Gouvernance

WorkOnIt suit actuellement un modèle de mainteneur principal.

- Le mainteneur `@NeKeR53` tranche roadmap, releases et fusions.
- Les décisions importantes commencent dans une issue publique.
- Les changements d'architecture significatifs sont documentés dans `docs/`.
- Les contributions restent propriété de leurs auteurs et sont proposées sous
  Apache-2.0 conformément au DCO.
- Aucun accès de commit n'est nécessaire pour contribuer.

La gouvernance pourra évoluer vers plusieurs mainteneurs lorsque participation
et responsabilité durables le justifieront. Toute évolution sera documentée ici.
