# Support

- Bug reproductible: ouvrez une issue avec le modèle « Bug ».
- Proposition: utilisez le modèle « Feature request ».
- Vulnérabilité ou donnée sensible: suivez [SECURITY.md](SECURITY.md).
- Question d'usage: ouvrez une discussion GitHub dans la catégorie adaptée.

WorkOnIt est maintenu bénévolement. Aucun délai de réponse ni support individuel
n'est garanti. Fournissez version, système, étapes, résultat attendu et résultat
observé; retirez toujours secrets et données privées.
